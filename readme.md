# SeatFlow

SeatFlow is a backend ticket-booking platform built to learn and demonstrate production-grade backend engineering concepts.

## Tech Stack

- Java 21
- Spring Boot
- Maven

## Current Features

- Spring Boot application setup
- Actuator health endpoint
- Application status endpoint

## Planned Concepts

- PostgreSQL
- Spring Data JPA
- REST API Design
- Validation
- Exception Handling
- Unit & Integration Testing
- Redis
- Concurrency Control
- Apache Kafka
- Microservices
- Saga Pattern
- Idempotency
- Transactional Outbox
- Docker
- Kubernetes
- Observability
- CI/CD
